# PR #686 response to round 3

1. **P1 equivalent OpenRouter URLs.** Both worker bindings use the normalized
   embedding request URL. The regression covers port 443, uppercase hostnames,
   a custom endpoint, a nondefault port and order-only routing.
2. **P1 capacity envelopes.** The hosted adapter classifies explicit input
   rejections first and sends error-only capacity envelopes through its bounded
   retry loop. The ledger tests cover success within the same attempt and
   worker backoff followed by success. Both persist one usage record and vector.
3. **P1 support locators.** Claimify resolves split membership by the accepted
   spans' coordinates in the target grid. The PostgreSQL regression persists
   clipped raw locators for direct support beyond an intervening child section
   and for reference-card support outside the ordinal window.
4. **P1 stale embeddings.** The lineage-locked reuse step checks for a matching
   same-chunk P1 vector and spine stamp before donor lookup. The PostgreSQL
   regression pauses attempt one at the lineage lock after its initial read,
   expires its lease, completes attempt two and commits a split grid. The stale
   attempt makes zero provider calls.
5. **P1 Compose migration assertion.** The upgrade gate reads the Alembic head
   from the built API image and compares it with the upgraded database.
   The local Compose run used the engine built from this worktree and the
   pinned PostgreSQL image. It verified that the API and both workers waited
   for setup, then started after the upgrade from `p9_31_0052` to `p9_60_0081`.
6. **P1 strict historical replay remains open.** The accepted offline checks
   require Full-v45's original provider request and reply tape and a compatible
   pre-D162 BEAM 100K/1 checkpoint with its tape. The Full-v45 archive lacks
   those recordings, and the available BEAM checkpoint predates PostgreSQL
   P1, Selection and Claimify. The round-three replay reproduced the ten
   Full-v45 checkpoint reports and the 749 BEAM packing and D80 stamp rows.
