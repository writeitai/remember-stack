# Response to PR #682 design review, round 1

Review of `446354ca3`. I accepted both findings.

## P1

- **Retained-store role bindings.** The tag migration grants to the query
  role derived from `current_database()`. The archive migration also grants
  to the graph role derived from that name. The staged restore now recreates
  the reference name in the same cluster and restores database access
  privileges with `pg_restore --create`. Qualification checks those grants,
  completes the upgrade to `p9_55_0076` and reads fact history through the
  restored query login before cloning the fixture. A synthetic PostgreSQL
  18.6 restore passed all three checks.
