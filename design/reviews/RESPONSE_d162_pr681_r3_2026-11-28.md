# Response to PR #681 design review, round 3

Review of `b31117c20`. Accepted both P1 findings and the P2. The review
reported no P0s.

## P1

1. **Find donors from clipped block passages.** E1's legacy chunk hash uses
   ordered normalized block hashes. Hashing the clipped passages recovers
   that candidate for an unchanged HTML comment between paragraphs and for
   a cut at a paragraph's former end. Both lookups verify the exact E2
   window before accepting a donor. An equal-length gap edit fails that check.
   [Source audit](../../plan/analysis/split_oversized_chunks_analysis.md#text-origin-at-a-split-boundary) ·
   [Lookup](../../plan/designs/split_oversized_chunks_design.md#2-split-only-failing-candidates).

2. **Recover legacy keys across a child section.** E2 reads the nearest
   parent chunk across the child. Legacy E1 left its content and origin
   slots empty. The design tries the empty pair and keeps it only after
   comparing the actual E2 windows. Acceptance requires a dated regression
   for an exact match and a changed window that uses the split and origin hashes.
   [E1 slots](../../src/rememberstack/workers/e1.py#L734-L765) ·
   [E2 window query](../../src/rememberstack/spine/chunk_catalog.py#L373-L419) ·
   [Acceptance](../../plan/designs/split_oversized_chunks_design.md#4-acceptance).
