# Response to PR #681 follow-up design review, round 3

Review of `446f7f2cf`. No P0 findings. Accepted both P1 findings, the P2
implementation note, and the schema nit.

## P1

**Fence fact application.** The entity stream admits assertions from
materialized units and later selects the earliest unapplied admission.
A worker releases the locks between prepare and apply, so reconcile's
selection check alone leaves an admitted assertion free to apply after a
repack. D162 now uses the lineage lock to serialize grid selection with
new admissions. The old grid stays selected while admitted assertions
drain. New admissions require a selected membership, using the existing
support-review lock order. The regression pauses a durable decision
before apply and checks a stale membership through a helper.

[Prepare and apply](../../src/rememberstack/spine/fact_adjudication.py#L297-L339) ·
[Support-review locks](../../src/rememberstack/spine/review.py#L601-L645) ·
[Fact-application fence](../../plan/designs/split_oversized_chunks_design.md#fact-application-fence).

**Restore reused testimony.** The prior-result lookup can find the
retired claim and attachment writes the remapped occurrence with the
same ID. Both reconcile modes now restore currency when completed,
verified reuse carries a claim whose last retirement was packing-only.
They record the restoration in D54's ledger, recount support, and
resolve the corresponding withdrawal flag when support returns. The
regression requires current-only search to return the original ID and
checks paid reuse and idempotency.

## P2

**Preserve legacy empty sources-only completions.** The old embed
payload gives the representation. With claims disabled, its completion
records gaps before any empty flush marker. D162 binds the successful
work to the proven historical generation or, after verifying empty E0,
to one configured empty grid. Deferred claims admission uses that
binding and readiness retains the original `finished_at`. The upgrade
regression covers both proof paths and rejects missing rows for a
nonempty representation.
