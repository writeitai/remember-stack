# Response to D162 design review, round 6

PR #681, reviewed head `338b1ec22`. Accepted all seven priority findings and
the replay nit.

Source probes reproduced the legacy D143 discharge race and D80's title
sensitivity when it renders a header. The pg_textsearch source archive
matched the image pin's SHA-256. Focused existing tests passed 54 cases
and skipped 134 PostgreSQL cases with `REMEMBERSTACK_DATABASE_URL` unset.
The new scenarios are specified as implementation release gates.
