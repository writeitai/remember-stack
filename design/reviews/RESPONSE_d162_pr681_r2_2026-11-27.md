# Response to PR #681 design review, round 2

Review of `5ce484a79`. Both findings accepted.

## P1

- **Text origin and extraction reuse across layouts.** E1's legacy keys
  include only adjacent chunks that share a section. E2 also sees the nearest
  same-section chunk across a nested section. An in-memory probe using the
  source query and hash functions reproduced the January-to-February reset
  and both extraction key misses in both layout directions. Intact targets
  keep the legacy calculations unless they consume a recut E2 neighbor. In
  that case both keys cover the final windows, including the tagged slice.
  The dated Appendix-only regressions require the original date, identical
  keys and claim IDs, and zero paid calls for the parent target. A control
  checks that cutting the same-section neighbor beyond the child changes both keys.
