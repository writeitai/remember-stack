# Response to PR #681 design review, round 3

Review of `0cee4cc0e`. Both P1 and both P2 findings accepted. The review
reported no P0 findings.

## P1

- **Recorded dates in private recovery.** The existing CHUNK replay uses
  committed rows. A new D140 lookup can miss after a neighbor changes,
  which would put the version date in the E2 header and on fresh claims.
  Recovery now carries the recorded date, including unknown, for every
  intact row and replacement span. Changed windows still get new keys.
  [CHUNK replay and date lookup](../../src/rememberstack/workers/e1.py#L132-L217) ·
  [E2 date and header](../../src/rememberstack/workers/e2.py#L1794-L1815) ·
  [Fresh claim assertion time](../../src/rememberstack/workers/e2.py#L1345-L1349) ·
  [D162 recovery](../../plan/designs/split_oversized_chunks_design.md#3-recover-through-chunk-while-the-grid-is-unpublished).
- **Equivalent inputs across a split.** The source probe reproduced equal
  text windows, D119 passages, converter origins and D80 inputs with
  unequal keys after tagging the first piece. D162 now keeps the intact
  target's two keys and date for an exact match, subject to D140 on a new
  version. The rule also covers a matching fitting grid after a split,
  including when its prior row carries D162 keys. D119 still verifies
  remapping and D122 still checks the ordered producers separately.
  [E1 keys](../../src/rememberstack/workers/e1.py#L656-L765) ·
  [D119 passages](../../src/rememberstack/core/source_passages.py#L109-L171) ·
  [D122 hash](../../src/rememberstack/core/selection_references.py#L70-L86) ·
  [D162 reuse](../../plan/designs/split_oversized_chunks_design.md#2-refine-only-failing-candidates).

## P2

- **Recovery grid.** The layer helper looks up the base embed component
  and the latest packing generation separately. Use the representation
  and full packing generation tied to the failed attempt for the recovery
  check and replay. Ambiguous legacy attempts stay dead-lettered.
  [Current lookups](../../src/rememberstack/spine/processing_layers.py#L1308-L1332) ·
  [D162 recovery](../../plan/designs/split_oversized_chunks_design.md#3-recover-through-chunk-while-the-grid-is-unpublished).

  Choose the first actual intersection within each split grid and include
  the existing matches from unsplit grids.
