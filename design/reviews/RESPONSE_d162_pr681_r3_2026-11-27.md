  fresh-store ranking and exact-call coverage applied to the superseded
  runtime gate. The release now requires hosted route qualification and an

  22,528 Qwen tokens. Ordered spans, IDs, hashes and full embedding inputs
  must match the stored grids byte for byte, with zero splits and zero model
  calls. Fresh-store HNSW sensitivity is a follow-up.

  whose vectors both passed P1 validation. E1 assigns them by request
  position and stamps the expected hashes. D162 now requires proof of the
  original request-to-vector mapping and full delivery, including for
  P1-only checkpoints. The recovery regression uses a duplicate-index
  batch followed by an oversize dead letter and requires paid calls only for
  passages without a verified donor.

links until first E1 publication, including in section references and
history. A touched in-force version can yield `scope_pending` and an empty
`boundary` response. Exercise the transition with one fitting grid and a
published legacy control in the existing publication checks. The changed
SQL view definitions also roll `surface_manifest_hash` and trigger standard
saved-query revalidation even for retained stores.
