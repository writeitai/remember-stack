# Response to PR #681 design review, round 3

Reviewed head `8393bdef8`. Accepted all three P1 findings, both P2 notes
and the citation nit. The review reported no P0 findings.

## P1

- **Benchmark reads.** LoCoMo dispatches live model-generated arguments
  after applying the benchmark budget. A saved trace can match while a
  new query ranks differently. Candidate dispatch now requires parity for
  the exact operation, resolved arguments and effective scope on the
  qualified snapshots. Uncovered calls use the pinned path until paired
  replay passes. The regression exercises a new query with a divergent
  ranking and a previously qualified query under a different scope.
  [LoCoMo dispatch](../../benchmarks/locomo/runner.py#L2392-L2420) ·
  [D162 §5](../../plan/designs/split_oversized_chunks_design.md#5-benchmark-admission-and-release-checks)
- **Legacy vector recovery.** The decoder accepted two replies with index `0`
  whose vectors both passed P1 validation. E1 assigns them by request
  position and stamps the expected hashes. D162 now requires proof of the
  original request-to-vector mapping and full delivery, including for
  P1-only checkpoints. The recovery regression uses a duplicate-index
  batch followed by an oversize dead letter and requires paid calls only for
  passages without a verified donor.
  [Legacy decoder](../../src/rememberstack/adapters/openrouter.py#L1052-L1077) ·
  [E1 assignment and stamps](../../src/rememberstack/workers/e1.py#L502-L572) ·
  [D162 §2](../../plan/designs/split_oversized_chunks_design.md#2-coordinates-and-reuse)
- **Citation catalogue.** Removing a fence outside three fixed slots
  changed one target passage into three with equal slot bytes and relative
  origin hashes. The old card remapped by substring without a destination
  label covering its span. Selection and Claimify reuse now compare ordered
  relative passage ranges whenever either grid is split, including equal
  packing stamps. Claimify also checks kept ranges, origin eligibility
  and admitted supports. The fence regression includes zero-call,
  same-claim-ID controls with matching inputs and catalogues.
  [Catalogue construction](../../src/rememberstack/core/source_passages.py#L124-L171) ·
  [Card remap](../../src/rememberstack/workers/extraction_references.py#L156-L218) ·
  [D162 §2](../../plan/designs/split_oversized_chunks_design.md#2-coordinates-and-reuse)
