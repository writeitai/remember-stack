## P2

An ordinary enqueue resolves to the existing CHUNK row. The ordinary handler
returns the embed continuation whenever it finds committed cuts. Size
recovery now calls the shared fit-and-refine routine directly and atomically
recuts and reopens the exact failed embed attempt. The acceptance check starts
with CHUNK already succeeded and requires a single recut and replay allowance
across repeated requests. It also checks a stale request after a later failure.
