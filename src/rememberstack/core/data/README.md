# Qwen3 embedding tokenizer

`qwen3_embedding_8b_tokenizer.json.gz` contains the unmodified tokenizer
from Qwen/Qwen3-Embedding-8B at revision
`1d8ad4ca9b3dd8059ad90a75d4983776a23d44af`. The source publishes it under
the Apache License 2.0, also available in the repository root. The gzip
wrapper can be reproduced with `gzip -n -9 -c tokenizer.json`.
[Upstream tokenizer and license](https://huggingface.co/Qwen/Qwen3-Embedding-8B/tree/1d8ad4ca9b3dd8059ad90a75d4983776a23d44af).
