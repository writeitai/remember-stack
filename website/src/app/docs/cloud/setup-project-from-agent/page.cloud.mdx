# Set up a Project from your agent

<AppliesTo products={["remember.dev"]} />

Your agent can create a project, set its monthly cap and issue a memory key
using the `remember` CLI. A person approves sign-in and completes the
activation purchase. To add a project, you need an organisation owner,
active billing, a paid Default project activation and a free project slot.

## Sign in and create the project

```bash
remember login
```

On the approval page, choose organisation-wide project coverage so the key
also covers the new project. Enable `account:manage` for project writes and
key management. Keep `account:read` for inspecting the project. The owner can
enable project creation and cap changes in **Settings → Agent permissions**.
Both switches are required when creating a project with a cap.

```bash
remember projects create --name "Billing migration" --monthly-cap 25.00
```

The command prints the new project ID and its Checkout URL. Use that ID as
`PROJECT_ID` in the commands below.

## Activate the project

Open the Checkout URL from `create` in a browser and complete payment. If
you need a fresh link for the unpaid project, run `activate` and open the
new URL. This replaces the previous unpaid link.

```bash
remember projects activate "$PROJECT_ID"
remember projects show "$PROJECT_ID"
```

After payment, use `show` to check `activation_state` and `deployment` while
remember.dev provisions the deployment. Wait for the deployment to become
active before sending it memory requests.

## Create and use a memory key

Give the new key access to this project and the memory permissions the agent
needs. This example issues a 30-day key for reading and writing memory. The
child key's expiry must fit within the lifetime remaining on your login key.

```bash
MEMORY_KEY=$(remember keys create --name "Billing migration memory" \
  --project "$PROJECT_ID" --permission memory:read --permission memory:write \
  --default-project "$PROJECT_ID" --lifetime-days 30)
REMEMBER_API_KEY="$MEMORY_KEY" remember ingest billing-migration.md --project "$PROJECT_ID"
```

The issuer returns the secret once. Store it where the agent reads its
credentials and use `REMEMBER_API_KEY` for subsequent memory commands.
See the [CLI reference](/docs/reference/cli#remember-keys).
