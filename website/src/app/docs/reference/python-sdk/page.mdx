# Python SDK

Pagination follows the shared [Pagination and truncation](/docs/reference/http-api#pagination-and-truncation) contract (D154).

<AppliesTo products={["remember.dev", "self-hosted"]} />

The `remember` package is the Python client for RememberStack. You use it to
store documents, wait until they are processed, and ask the memory what it
knows.<Cloud> The same code runs against remember.dev and against an engine you host
yourself; only the key differs.</Cloud>

This page lists every public name the package exports. For the fields inside
a result (facts, claims, validity windows, negatives), see
[Result types](/docs/reference/result-types).

## Install

```bash
pip install remember
```

The package needs Python 3.12 or newer. It depends only on `httpx`,
`pydantic` and `pydantic-settings`; it does not contain the engine. To run the
engine, see [Install with Docker Compose](/docs/self-hosting/install).

`pip install remember` also installs the `remember` command. See
[CLI](/docs/reference/cli).

The client is synchronous. There is no async client yet
([What is not built yet](/docs/project/not-built-yet)).

## Which client to use

| You want to | Use |
|---|---|
| Store and retrieve memory (the usual case) | `Client` (same as `RememberClient`) |
| The same, without the file-path `ingest` shortcut<Cloud> and without `account`</Cloud> | `MemoryClient` |

`Client` is a subclass of `MemoryClient`. Every method listed under
[MemoryClient](#memoryclient) is available on `Client`.

## Connecting

`Client` and `MemoryClient` resolve their connection the way the CLI does,
with one function, `remember.resolve_connection()`. Each setting is resolved
on its own; first match wins:

| Setting | 1. Argument | 2. Environment | 3. Credential file | 4. Otherwise |
|---|---|---|---|---|
| Key | `api_key` | `REMEMBER_API_KEY` | `key` | no key |
| Address | `base_url` | `REMEMBER_API_URL` | `api_url` | `http://127.0.0.1:8000`<Cloud>, or the project's address for a remember.dev key</Cloud> |
| Project | `project` | `REMEMBER_PROJECT` | `default_project` | none<Cloud>, or the key's default project</Cloud> |

The credential file is the one the CLI writes
([CLI: credential file](/docs/reference/cli#credential-file)). It is read only
when a setting is not given as an argument or in the environment.

A key read from the credential file is only sent to the address stored
beside it<Cloud>, to remember.dev, or to a project address remember.dev
returns for that key</Cloud>. When `base_url` or `REMEMBER_API_URL` names
another address, the first request raises `StoredKeyRefused`; pass the key
explicitly to use it there. A key you pass as an argument or in
`REMEMBER_API_KEY` is sent wherever you point it.

<Tabs>

<Tab cloud label="remember.dev">

```python
import remember

memory = remember.Client(api_key="rmb_…")                   # the key's default project
docs = remember.Client(api_key="rmb_…", project="docs")    # another project it covers
```

A remember.dev key names projects, not addresses. On the first request the
client asks remember.dev which address serves the project, checks that the
key covers it and that the address is `https`, and then talks to that
address directly; memory traffic never passes through remember.dev's
console. The answer is reused for 10 minutes. If the address stops answering,
the client asks again for the same project. Only a classified read retries
once when the address changed, after a network failure, `421`, or a `404` that
is not the engine's error envelope. This includes read-only POST requests such
as SQL queries, graphs and readiness. Writes are never repeated, including
connect errors and `421`; movement refreshes their mapping for the next call.
Timeouts never cause re-resolution or replay.
When the project cannot be resolved it raises `ProjectResolutionError`; it
never falls back to a local engine.

## Client

```python
class remember.Client(MemoryClient)
remember.RememberClient = remember.Client
```

The client for one deployment. It talks directly to the deployment's own
address<Cloud>; remember.dev never proxies your queries through its console</Cloud>.

### Constructor

```python
Client(
    *,
    api_key: str | None = None,
    base_url: str | None = None,
    project: str | None = None,
    timeout: float = 300.0,
    client: httpx.Client | None = None,
    transport: httpx.BaseTransport | None = None,
)
```

All parameters are keyword-only.

| Parameter | Meaning |
|---|---|
| `api_key` | The API key. A bare key or a full `Bearer …` value. |
| `base_url` | The deployment address. |
| `project` | Which project to use, by id or name, when the key covers several.<Cloud> Only a remember.dev key uses it.</Cloud> |
| `timeout` | Seconds per HTTP request. Default 300. |
| `client` | An `httpx.Client` you built yourself, with its own address and headers. It cannot be combined with any other parameter, and nothing is resolved. The SDK does not close a client you pass in. |
| `transport` | An `httpx` transport to use instead of the network (for tests or a proxy). |

How each setting is chosen: [Connecting](#connecting). Creating a client
makes no network call.

Raises:

- `ValueError` when `client` is combined with another parameter.
- `ValueError` when the key is empty, is the bare word `Bearer`, or contains a
  line break.
- `remember.credentials.CredentialError` when the credential file has to be
  read and is unreadable or not in the current format.

### `client.account`

```python
Client.account -> AccountApi
AccountApi.whoami() -> dict[str, object]
AccountApi.get(path: str, *, params: Mapping[str, str | int] | None = None) -> object
```

Calls remember.dev's account API with the same key. `whoami()` returns what
remember.dev knows about the key: the person, organisation, role, projects
and permissions. `get(path)` reads any other route of the account API
([Account API](/docs/reference/cloud-api)); `path` is relative to it, for
example `"/v1/keys/self"`. Account calls need the `account:read` permission
on the key.

Raises `AccountApiUnavailable` when the key is not a remember.dev key (for
example a self-hosted engine's key). Memory calls are unaffected.

```python
me = remember.Client(api_key="rmb_…").account.whoami()
```

### Context manager

`with remember.Client() as memory:` returns the client and closes its HTTP
connection pool when the block ends. Outside a `with` block, call
`memory.close()` yourself. `close()` closes only a connection pool the SDK
created; a `client=` you injected stays open.

### Store

#### `ingest`

```python
MemoryClient.ingest(
    source: bytes | Path | str | None = None,
    *,
    content: bytes | None = None,
    filename: str | None = None,
    mime: str | None = None,
    title: str | None = None,
    source_kind: str | None = None,
    source_ref: str | None = None,
    source_modified_at: datetime | None = None,
    versioning_mode: Literal["snapshot", "living"] = "snapshot",
    source_version_ref: str | None = None,
    source_path: str | None = None,
    version_key: str | None = None,
    effective_from: datetime | None = None,
    effective_until: datetime | None = None,
    tags: Sequence[str] | None = None,
) -> IngestedVersion
```

Uploads one document. The call returns as soon as the engine has stored the
bytes; processing runs afterwards. Wait with
[`wait_for_readiness`](#wait_for_readiness) before you expect the content in
results.

| Parameter | Meaning |
|---|---|
| `source` | A `Path` or `str` file path (read from disk), or `bytes`. |
| `content` | Raw bytes. Wins over `source` when both are given; `source` then only supplies the fallback filename. For a string path this is `str(Path(source))`, which normalizes redundant separators and `./`. Set `filename` explicitly to control the name. |
| `filename` | Required for bytes. Defaults to the file's name for a path. |
| `mime` | Media type; an explicit value always wins. Defaults to the type of the extension of the file's real name (for a path) or of `filename` (for bytes): `.md` is `text/markdown`, `.pdf` is `application/pdf`, on every Python installation; the full table is in [Ingest files](/docs/guides/ingest-files#the-mime-type). An extension outside that table takes the type your Python installation's MIME database gives it, or `application/octet-stream` if it has none. The engine converts only media types it has a converter for; see [File formats and converters](/docs/self-hosting/converters). |
| `title` | A human title for the document. |
| `source_kind`, `source_ref` | The document's stable identity: what kind of source it is and its id within that kind. Always together. Ingesting again with the same pair creates a new version of the same document when the bytes differ. See [Documents, versions and sources](/docs/concepts/documents-and-sources). |
| `source_modified_at` | When the source itself last changed. Must be timezone-aware UTC. Requires `source_kind`/`source_ref`. |
| `versioning_mode` | `"snapshot"` (default) or `"living"`. `"living"` requires `source_kind`/`source_ref`. See [Updating a source](/docs/concepts/updating-sources). |
| `source_version_ref` | The source system's own revision label. Requires `source_kind`/`source_ref`. |
| `source_path` | Where the file lives at its source, such as a folder path or a URL. Recorded with the version's names; sending the same bytes again with a different `filename`, `title` or `source_path` records the new name without creating a version. See [File names, titles and paths](/docs/reference/http-api/ingest#file-names-titles-and-paths). |
| `version_key` | Your permanent name for this version, unique within the document (1 to 512 characters). A key new to the document always creates a version; the latest version's key is accepted again only with the same bytes. Requires `source_kind`/`source_ref`. See [Versions in force](/docs/reference/http-api/ingest#versions-in-force). |
| `effective_from` | Start (included) of the period this version's text is in force. Timezone-aware UTC. Requires `source_kind`/`source_ref` and `versioning_mode="snapshot"`. |
| `effective_until` | End (excluded) of that period, later than `effective_from`. Timezone-aware UTC. Omitted: the period lasts until the next declared start. |
| `tags` | Registered tags, each a name (any letter case) or `tag_id`, added to the document's tags; at most 64. Ingest only adds tags and they never decide whether a version is created. See [Tags](/docs/reference/http-api/ingest#tags). |

Raises `ValueError` when:

- only one of `source_kind` and `source_ref` is given;
- `source_modified_at`, `source_version_ref`, `versioning_mode="living"`,
  `version_key`, `effective_from` or `effective_until` is given without
  `source_kind`/`source_ref`;
- `source_modified_at`, `effective_from` or `effective_until` is naive or not
  UTC;
- `effective_until` is given without `effective_from`, or is not later than
  it, or a period is given with `versioning_mode="living"`;
- neither `source` nor `content` is given;
- bytes are given without `filename`;
- `tags` is a single string instead of a sequence.

Reading a path can raise `OSError`: `FileNotFoundError` when it does not
exist, whether given as `Path` or `str`.

Returns [`IngestedVersion`](#models). `created` is `False` when these exact
bytes were already stored for this document; no new processing starts. A
`version_key` that names another version, or a start that another version
already declares, raises `MemoryApiError` with `status_code` 409; a period
on a `living` document raises it with 422. A tag that is not registered
raises [`UnknownTag`](#unknowntag) and nothing is stored.

```python
from datetime import UTC, datetime
from pathlib import Path

version = memory.ingest(
    Path("specs/billing-migration.md"),
    title="Billing migration spec",
    source_kind="notes",
    source_ref="specs/billing-migration.md",
    source_modified_at=datetime(2026, 9, 21, 14, 0, tzinfo=UTC),
)
print(version.doc_id, version.version_id, version.created)
```

#### `pipeline_readiness`

```python
MemoryClient.pipeline_readiness(
    *, version_ids: tuple[UUID, ...], require: ReadinessRequirements
) -> PipelineReadinessReport
```

Asks, once, whether the given versions have finished processing and whether
the capabilities you name are ready. `require` must name all four
capabilities (`pipeline`, `p1`, `live_graph`, `p3`) as `True` or `False`.

Raises `ValueError` when `version_ids` is empty.

```python
report = memory.pipeline_readiness(
    version_ids=(version.version_id,),
    require=remember.ReadinessRequirements(
        pipeline=True, p1=True, live_graph=True, p3=False
    ),
)
for v in report.versions:
    print(v.version_id, v.ready, [(s.stage, s.status) for s in v.stages])
```

What each capability means: [The pipeline and readiness](/docs/concepts/pipeline).

#### `wait_for_readiness`

```python
MemoryClient.wait_for_readiness(
    version_ids: Sequence[str | UUID],
    *,
    timeout: float = 1800.0,
    poll_interval: float = 15.0,
    require_p3: bool = False,
) -> PipelineReadinessReport
```

Calls `pipeline_readiness` at once and then every `poll_interval` seconds
until the report says `ready`, requiring `pipeline`, `p1` and `live_graph`
(and `p3` when `require_p3=True`). Returns the ready report. The defaults,
30 minutes and 15 seconds, are starting points sized for single documents;
raise `timeout` for bulk loads.

A stage that is `failed` has a retry scheduled, so the method keeps
polling. A stage that is `dead_letter` has used all its attempts and never
becomes ready, so the method stops at once.

Raises:

- [`PipelineDeadLettered`](#pipelinedeadlettered) when any stage of any
  listed version is `dead_letter`;
- `TimeoutError` when `timeout` seconds pass first;
- `ValueError` when an id is not a UUID.

See [Wait until a document is queryable](/docs/guides/wait-for-readiness).

```python
memory.wait_for_readiness([version.version_id])
```

```python
) -> DocumentPage
```

Returns one page of the deployment's documents, newest document first, as a
[`DocumentPage`](/docs/reference/result-types#documentpage). Pass the
returned `next_cursor` as `cursor` to read the next page; it is `None` on the last page.
`status` keeps only documents whose newest version has that status. `limit`
is 1 to 200; the deployment answers `422` outside that range. Deleted
documents are not listed. See
[`GET /documents`](/docs/reference/http-api/ingest#get-documents).

```python
cursor = None
while True:
    page = memory.list_documents(cursor=cursor)
    for document in page.documents:
        print(document.doc_id, document.title, document.serving)
    if page.next_cursor is None:
        break
    cursor = page.next_cursor
```

#### `search_documents`

```python
MemoryClient.search_documents(
    query: str | None = None,
    *,
    filters: DocumentSearchFilters | None = None,
    versions: Literal["current", "all"] = "current",
    k: int = 20,
    limit: int = 50,
    cursor: str | None = None,
    time: ReadTime | None = None,
) -> DocumentSearchPage
```

Finds documents by the names they were stored under, their general metadata
and their text, and returns a
[`DocumentSearchPage`](/docs/reference/result-types#documentsearchpage).
`filters` is a
[`DocumentSearchFilters`](/docs/reference/result-types#documentsearchfilters)
(`from remember import DocumentSearchFilters`): `family`, `authors`,
`recipients`, the `created_*`/`modified_*` ranges, `language`, `thread_ref`,
`doc_ids` and `tags`, a
[`DocumentTagFilter`](/docs/reference/result-types#documenttagfilter)
(`all`, `any`, `none`) of tag names or ids. With a `query` the results are ranked and not paged; without
one they are newest ingested first and `limit` (default 50) / `cursor` pages them.
Read `next_cursor` for continuation; ranked responses disclose `truncated`. Passing `cursor` with a
`query`, a date without a timezone, `k` / `limit` outside 1 to 200, or an
empty or repeating tag list raises `pydantic.ValidationError` before any
request. A malformed cursor raises `MemoryApiError` with `status_code` 400; a
tag that is not registered raises `remember.UnknownTag`, whose `tags` lists
every one. `time` decides which editions of a
document with declared effective periods are candidates (default: the ones
in force now); it takes the same values as in [`search_chunks`](#search_chunks).
What matches, and how, is in
[`POST /documents/search`](/docs/reference/http-api/ingest#post-documentssearch).

The result's `p3_path` is relative to the corpus root and non-null only when
that version is served and its nullable publication marker matches current
export inputs. Historical, raw-only, unpublished, updating and failed
publications return `None`. `served_version` describes currency independently.
Resolve again with `DocumentSearchFilters(doc_ids=(doc_id,))` after a
folder move; [suffix lookup](/docs/self-hosting/filesystem-views#layout) works
offline. Only the suffix is stable within a folder path.

```python
from remember import Client, DocumentSearchFilters

memory = Client()
page = memory.search_documents("audit report")
emails = memory.search_documents(
    filters=DocumentSearchFilters(authors=("alice@acme.com",)), limit=50
)
if len(emails.people_matched) > 1:
    print("several people matched:", emails.people_matched)

from remember import DocumentTagFilter

decisions = memory.search_documents(
    filters=DocumentSearchFilters(
        tags=DocumentTagFilter(all=("kind:decision",), none=("project:ci-smoke",))
    )
)
```

#### `delete_document`

```python
MemoryClient.delete_document(*, doc_id: UUID | str) -> DocumentDeletion
```

Removes one document, every version of it, from the memory and returns a
[`DocumentDeletion`](/docs/reference/result-types#documentdeletion) with
`doc_id`, `deleted_at`, `claims_retired`, `relations_closed` and
`observations_closed`. Its claims stop counting as evidence, and facts that
only it supported are closed with a recorded retraction. The claims and the
stored original are kept as history. Needs a `write` credential. See
[`DELETE /documents/{doc_id}`](/docs/reference/http-api/ingest#delete-documentsdoc_id).

Raises `ValueError` before sending anything when `doc_id` is not a UUID, and
`MemoryApiError` with `status_code` 404 and `detail` `"document_not_found"`
when the document does not exist or is already deleted.

```python
from remember import MemoryApiError

try:
    deletion = memory.delete_document(doc_id=version.doc_id)
    print(f"{deletion.claims_retired} claims retired")
except MemoryApiError as error:
    if error.status_code != 404:
        raise
```

### Tags

Tags are names you register, such as `project:billing-migration`, each with
a description, and assign to documents. A walkthrough is in
[Tag documents](/docs/guides/tag-documents). Wherever a method takes a
`tag`, it accepts the name in any letter case or the `tag_id`. Every method
here except `list_tags` needs a `write` credential.

#### `list_tags`

```python
MemoryClient.list_tags(*, query: str | None = None) -> TagList
```

Returns every registered tag, ordered by name ignoring letter case, as a
`TagList` whose `tags` are [`Tag`](/docs/reference/result-types#tag) models
(`tag_id`, `name`, `description`, `created_at`, `updated_at`). `query`
(1 to 200 characters) keeps the tags whose name or description contains it,
ignoring letter case.

#### `create_tag`

```python
MemoryClient.create_tag(*, name: str, description: str) -> Tag
```

Registers a tag. The name is normalized to Unicode NFC and must be 1 to 128
characters with no whitespace or control characters; the description is at
most 2,000 characters. Raises `pydantic.ValidationError` for a name or
description that breaks these rules, before any request, and
`MemoryApiError` with `status_code` 409 and `code` `"conflict"` when the
name is already registered in any letter case, or `code`
`"tag_limit_exceeded"` when the deployment has 10,000 tags.

#### `update_tag`

```python
MemoryClient.update_tag(
    *,
    tag: UUID | str,
    name: str | None = None,
    description: str | None = None,
) -> Tag
```

Renames a tag, changes its description, or both; give at least one
(`pydantic.ValidationError` otherwise). Documents keep the tag, and the old
name stops resolving at once. A name is first looked up with
`GET /tags?name=…`, which the engine matches the way it matches every tag
name; a tag that is not registered raises [`UnknownTag`](#unknowntag) with
`status_code` 404. A new name another tag has raises `MemoryApiError` 409
with `code` `"conflict"`.

#### `delete_tag`

```python
MemoryClient.delete_tag(*, tag: UUID | str) -> Tag
```

Deletes the tag and removes it from every document that carries it, and
returns the deleted `Tag`. An unregistered tag raises `UnknownTag` with
`status_code` 404.

#### `update_document_tags`

```python
MemoryClient.update_document_tags(
    *,
    doc_id: UUID | str,
    add: Sequence[str] | None = None,
    remove: Sequence[str] | None = None,
    set: Sequence[str] | None = None,
) -> DocumentTags
```

Changes one document's tags in one step and returns a
[`DocumentTags`](/docs/reference/result-types#documenttags) with the tags
afterwards. Give `add` and `remove`, or `set` to replace the whole set
(`set=[]` removes every tag); each list holds at most 64 tags. Removing a
registered tag the document does not carry is not an error. Changing tags
starts no processing.

Raises `ValueError` before sending anything when `doc_id` is not a UUID or a
list is a single string, `pydantic.ValidationError` when `set` is combined
with `add` or `remove`, `UnknownTag` when a tag is not registered (nothing
changes), and `MemoryApiError` with `status_code` 404 for an unknown or
deleted document, or 409 with `code` `"tag_limit_exceeded"` past 64 tags.

```python
tags = memory.update_document_tags(
    doc_id=version.doc_id, add=["project:billing-migration", "kind:decision"]
)
print(tags.tags)
```

### Versions in force, sections and references

What these methods are for, with a worked example:
[Read a document as of a date](/docs/guides/versions-in-force).

#### `set_effective_periods`

```python
MemoryClient.set_effective_periods(
    *,
    doc_id: UUID | str,
    version_id: UUID | str,
    periods: Sequence[EffectivePeriodInput],
) -> EffectivePeriodsSet
```

Replaces the periods during which one version's text is in force.
`periods` is the version's complete set: each `EffectivePeriodInput` has
`effective_from` and an optional `effective_until`, both timezone-aware UTC
`datetime` values (or ISO 8601 strings with a zero offset). Periods not
listed are withdrawn and new ones declared, in one step. An empty sequence
leaves the version with no period while the document keeps reading by
period. Needs a `write` credential. Raises `pydantic.ValidationError`
before any request for an end not after its start, two periods with the
same start, or more than 1,000 periods; `MemoryApiError` with
`status_code` 409 when another version declares the same start, 422 for a
`living` document, 404 for an unknown document or version. See
[`PUT …/effective-periods`](/docs/reference/http-api/ingest#put-documentsdoc_idversionsversion_ideffective-periods).

#### `clear_effective_time`

```python
MemoryClient.clear_effective_time(*, doc_id: UUID | str) -> EffectiveTimeCleared
```

Withdraws every declared period of a document and returns it to "the newest
processed version is current". `cleared_at` is `None` when the document had
no declared periods. Needs a `write` credential. Raises `MemoryApiError`
with `status_code` 404 for an unknown or deleted document.

#### `set_references`

```python
MemoryClient.set_references(
    *,
    doc_id: UUID | str,
    version_id: UUID | str,
    references: Sequence[ReferenceInput],
) -> ReferencesSet
```

Replaces one version's supplied references, sent as NDJSON. `ReferenceInput`
has `kind`, `from_section_key`, `target` (a `ReferenceTarget` with
`source_kind`, `source_ref`, `version_key`, `section_key`), `binding`,
`change_effective_from`, `change_date_known`, `source_label` and `context`;
its rules are checked when you build it. `outcome` is `created`,
`unchanged` or `pending_cancelled`. Needs a `write` credential. Raises
`MemoryApiError` with `status_code` 404, 413 (over 64 MiB) or 422. See
[`PUT …/references`](/docs/reference/http-api/ingest#put-documentsdoc_idversionsversion_idreferences).

#### `reference_generations`

```python
MemoryClient.reference_generations(
    *, doc_id: UUID | str, version_id: UUID | str
) -> ReferenceGenerations
```

Returns the version's reference generations, newest first, each with its
`status` (`pending`, `active`, `rejected`, `superseded`) and `errors`.

#### `section_history`

```python
MemoryClient.section_history(

    limit: int = 50,
    cursor: str | None = None,
) -> SectionHistoryPage
```

Follows one keyed section across the document's versions. `time` defaults

prepared `SectionHistoryRequest`. See
[`GET …/sections/{section_key}/history`](/docs/reference/http-api/sections-and-references#get-documentsdoc_idsectionssection_keyhistory).

```python
page = memory.section_history(doc_id=doc_id, section_key="per-diem")
```

#### `document_references`

```python
MemoryClient.document_references(

    chunk_id: UUID | str | None = None,

    section_key: str | None = None,
```

Lists what a passage (`chunk_id`) or a document or section (`doc_id`, with

prepared `DocumentReferencesRequest`. See
[`POST /documents/references`](/docs/reference/http-api/sections-and-references#post-documentsreferences).

```python
page = memory.document_references(doc_id=doc_id, section_key="approvals", direction="outgoing")
```

### Assured operations

The four assured operations are the recommended way to ask the memory a
question. Their full contracts are in
[Assured operations](/docs/reference/assured-operations).

#### `list_operations`

```python
MemoryClient.list_operations() -> tuple[ToolDescriptor, ...]
```

Returns the descriptors of the deployment's operations: `resolve_entity`,
`claims_and_sources_context`, `facts_context`, `combined_context`. Each
descriptor carries the operation's input schema.

```python
for op in memory.list_operations():
    print(op.name, op.version, op.input_schema.get("required"))
```

#### `run_operation`

```python
MemoryClient.run_operation(
    *,
    name: str,
    arguments: Mapping[str, object] | None = None,
    layers: Sequence[str] | None = None,
) -> Envelope | ContextBundleV2
```

`layers` narrows the processing layers the operation may read (any of
`"sources"`, `"claims"`, `"facts"`; default every layer the deployment
serves). See [Narrowing a read to layers](/docs/concepts/retrieval#narrowing-a-read-to-layers).

Runs one operation by name with its JSON arguments. Returns a
`ContextBundleV2` when the response is a combined bundle, otherwise an
`Envelope`. Use it for arguments the convenience methods below do not expose
(`k`, `evidence_per_fact`, `candidate_k`, `entity_ids` on
`claims_and_sources_context`).

The engine validates arguments and answers with an error (raised as
`MemoryApiError`) for an unknown name, a missing required argument, an
unknown argument or a value outside its bounds.

```python
result = memory.run_operation(
    name="facts_context",
    arguments={"query": "Who owns the billing migration?", "k": 25},
)
```

#### `facts_context`

```python
MemoryClient.facts_context(
    query: str,
    *,
    k: int | None = None,
    candidate_k: int | None = None,
    time: Mapping[str, object] | None = None,
    hops: int | None = None,
    predicate: str | None = None,
    entity_ids: Sequence[str | UUID] | None = None,
    documents: DocumentSearchFilters | Mapping[str, object] | None = None,
) -> Envelope
```

Returns the facts the memory holds true that match `query`, with their
evidence.

| Argument | Constraint (checked by the engine) |
|---|---|
| `query` | 1 to 8,192 characters |
| `time` | `{"mode": "current"}` (default), `{"mode": "at", "at": "<ISO date-time>"}`, `{"mode": "overlap", "from": "…", "to": "…"}` or `{"mode": "history"}` |
| `hops` | 1 or 2; default 1 |
| `predicate` | 1 to 200 characters |
| `entity_ids` | 1 to 19 unique entity UUIDs |
| `documents` | a [documents filter](/docs/reference/assured-operations#the-documents-filter), as `DocumentSearchFilters` or a dict; tags must be registered (`remember.UnknownTag` otherwise) |

```python
facts = memory.facts_context(
    "billing migration owner", time={"mode": "history"}
)
billing = memory.facts_context(
    "cutover date", documents={"tags": {"all": ["project:billing-migration"]}}
)
for link in billing.fact_evidence:
    print(link.stance, link.claim_id, link.in_documents_filter)
for fact in facts.facts:
    print(fact.label, fact.validity.valid_from, fact.validity.valid_until)
```


`k` controls confirmed results per type (default 50, range 1–100).
`candidate_k` controls internal search depth (1–400, at least k); omitted depth
is max(4*k, 60), which is 200 at the default k.

#### `claims_and_sources_context`

```python
MemoryClient.claims_and_sources_context(
    query: str,
    *,
    k: int | None = None,
    candidate_k: int | None = None,
    time: Mapping[str, object] | None = None,
    layers: Sequence[str] | None = None,
    documents: DocumentSearchFilters | Mapping[str, object] | None = None,
) -> Envelope
```

Returns what sources said about `query` (claims) and the matching source
passages (chunks). `query` is 1 to 8,192 characters. `time` takes the same
values as in `facts_context`; for documents with declared effective periods
it reads only the text in force for that scope (default: now). `documents`
returns only what matching documents say. See
[Assured operations](/docs/reference/assured-operations#claims_and_sources_context).

```python
said = memory.claims_and_sources_context("Why was the cutover date moved?")
for claim in said.evidence:
    print(claim.claim_text, claim.asserted_at, claim.document_title)
```


`k` controls confirmed results per type (default 50, range 1–100).
`candidate_k` controls internal search depth (1–400, at least k); omitted depth
is max(4*k, 60), which is 200 at the default k.

#### `combined_context`


```python
bundle = memory.combined_context("What did John decide about invoicing?")

```


`k` controls confirmed results per type (default 50, range 1–100).
`candidate_k` controls internal search depth (1–400, at least k); omitted depth
is max(4*k, 60), which is 200 at the default k.

### SQL and saved queries

SQL queries run over the query space (`memory_v1`): prepared, read-only
views and functions. The engine parses every statement and validates it
against the query space before it runs; anything outside it is rejected.
See [Query space memory_v1](/docs/reference/query-space) and
[Explore memory with SQL](/docs/guides/sql). Failures carry a code on
`MemoryApiError.code` (for example `relation_not_allowed`,
`statement_timeout`); the list is in [Errors](/docs/reference/errors).

#### `query_sql`

```python
MemoryClient.query_sql(

    max_rows: int | None = None,

) -> dict[str, object]
```

Runs one statement with positional parameters (`$1`, `$2`, …). Returns the
`QueryResult/v1` object as a dict. `max_rows` must be between 0 and 1,000; larger values are refused.

#### `open_query`

```python
MemoryClient.open_query(
    sql: str, *, parameters: Sequence[object] = (), max_rows: int | None = None
) -> QueryResultDict
```

The same call, returning a [`QueryResultDict`](#models) with `.rows`,
`.columns` and `.truncated` attributes.

```python
res = memory.open_query(
    "SELECT predicate, count(*) AS n FROM facts_current GROUP BY 1 ORDER BY 2 DESC LIMIT $1",
    parameters=[10],
)
for row in res.rows:
    print(row)
```

```python
MemoryClient.explain_sql(
    *,

    layers: Sequence[str] | None = None,
```

Checks and plans a statement without running it. Returns `QueryResult/v1`
as a dict.

#### `explain_query`

```python
MemoryClient.explain_query(
```

`explain_sql` returning a `QueryResultDict`.

```python
MemoryClient.describe_query_space(
```

Returns the query space's views, functions, comments and limits. `pattern`


Searches the query space's own documentation (never your data). Each hit has

#### `call_open_query`

```python
MemoryClient.call_open_query(*, name: str, arguments: Mapping[str, object]) -> object
```

Runs one of the seven SQL query tools by its MCP tool name (`query_sql`,

## Errors

```text
RuntimeError
├── MemoryApiError                 every memory call
│   ├── RateLimited                429 from the deployment's admission limits
│   ├── LayerUnavailable           409 layer_unavailable
│   ├── UnknownTag                 unknown_tag
│   └── StoredKeyRefused           the stored key may not go to that address
└── PipelineDeadLettered           wait_for_readiness
Exception
└── ConnectorNotFoundError         exported, not raised today
ValueError
└── CredentialError                remember.credentials (the credential file)
```

<Cloud>

A remember.dev key adds two subclasses of `MemoryApiError`:
`ProjectResolutionError` (remember.dev could not resolve the project) and
`AccountApiUnavailable` (`client.account` without a remember.dev key).

</Cloud>

### MemoryApiError

Raised by every memory-client method when a request fails.

| Attribute | Meaning |
|---|---|
| `retryable`, `request_id` | Optional typed server diagnostics; they do not authorize automatic replay. |
| `status_code` | HTTP status. `0` means the request never got an answer (connection refused, timeout, DNS). `200` means the answer did not match the expected shape. |
| `detail` | The error text from the deployment. |
| `code` | A machine code, set for SQL and saved-query routes (for example `parse_error`, `quota_exceeded`, `saved_query_not_found`), for a `429` (`rate_limited` or `concurrency_limited`), and for the tag refusals `unknown_tag`, `conflict` and `tag_limit_exceeded`; otherwise `None`. |
| `response` | Not set by the SDK (`None`). |

`str(error)` reads `API <status_code>: <detail>`.

```python
try:
    memory.query_sql(sql="SELECT * FROM pg_catalog.pg_class")
except remember.MemoryApiError as error:
    print(error.status_code, error.code)   # 422 relation_not_allowed
```

Status codes and their meaning: [Errors and status codes](/docs/reference/errors).

### RateLimited

Raised when the deployment refuses a request with `429` because a key or the
deployment has reached its request-rate or in-flight limit. `code` is
`rate_limited` or `concurrency_limited`; `retry_after` is the `Retry-After`
the deployment sent, in seconds (a `float`), or `None`. The client does not
retry by itself.

```python
import time

try:
    memory.facts_context("Who owns the billing migration?")
except remember.RateLimited as error:
    time.sleep(error.retry_after or 1)
```

### StoredKeyRefused

Raised on the first request when the key came from the credential file and
the address came from `base_url` or `REMEMBER_API_URL` and is not an address
that key may be sent to ([Connecting](#connecting)). Pass the key as
`api_key` or in `REMEMBER_API_KEY` to use it there.

### LayerUnavailable

A `MemoryApiError` (`status_code` 409, `code` `layer_unavailable`) raised when
a read needs a [processing layer](/docs/concepts/pipeline#processing-layers)
the deployment does not process. `layer` is `"claims"` or `"facts"`. Check
[`processing_layers`](#processing_layers) and use a read the deployment
serves.

### UnknownTag

A `MemoryApiError` (`code` `unknown_tag`) raised when a call names a tag the
deployment has not registered. `tags` is a tuple of every unregistered tag
as the call gave it. `status_code` is 422 for tags in `ingest` or
`update_document_tags`, and 404 when `update_tag` or `delete_tag` cannot find
the tag. Nothing was stored or changed. Register the tag with
[`create_tag`](#create_tag), or check the spelling with
[`list_tags`](#list_tags).

```python
try:
    memory.ingest("notes/billing-sync.md", tags=["project:biling-migration"])
except remember.UnknownTag as error:
    print("not registered:", error.tags)
```

### PipelineDeadLettered

Raised by `wait_for_readiness` when a stage of a version it waits on is
`dead_letter`: the stage used all its retry attempts and will not finish by
waiting.

| Attribute | Meaning |
|---|---|
| `dead_lettered` | Every dead-lettered stage found, as `(version_id, stage, status)` tuples. |
| `report` | The `PipelineReadinessReport` that showed them. |

`str(error)` names each version and stage. On a self-hosted deployment the
operator can replay the work after fixing the cause<Cloud>; on remember.dev,
report the `version_id` and stage to support</Cloud>. See
[When a version fails](/docs/guides/wait-for-readiness#when-a-version-fails).

### CredentialError

`remember.credentials.CredentialError` (a `ValueError`) is raised when the
credential file cannot be read or written safely: it is a symlink, it is
readable by group or others, it is not a version-2 file, or the lock cannot be
taken. `remember setup --self-hosted` replaces the file<Cloud>, and so does
`remember login`</Cloud>.

<Cloud>

### ProjectResolutionError and AccountApiUnavailable

`ProjectResolutionError` is raised when remember.dev cannot resolve the
project for a key: the project is unknown, the key does not cover it, the
answer is unusable, or remember.dev cannot be reached. The message names the
project and the issuer. `AccountApiUnavailable` is raised by
`client.account` when the key is not a remember.dev key.

</Cloud>

### ConnectorNotFoundError

Exported for the connector methods; nothing raises it today.

## Models

Field-level detail for results is in [Result types](/docs/reference/result-types). The
models below are Pydantic models (frozen) unless noted.

| Name | What it is |
|---|---|
| `Envelope` | The result of every retrieval call: `grain`, `temporal_scope`, `entities`, `facts`, `evidence`, `chunks`, `sources`, graph fields, `truncation`, `negative`, `freshness` and more. |
| `ContextBundleV2` | The result of `combined_context`: `contract` (`"ContextBundle/v2"`), `claims_and_sources` (an evidence `Envelope`) and `facts` (a fact `Envelope`). |
| `IngestedVersion` | The result of `ingest`: `deployment_id`, `doc_id`, `version_id` (UUIDs), `content_hash` (str), `created` (bool), and the settings in force: `mime` (str), `title` (str or `None`), `versioning_mode` (`"snapshot"` or `"living"`), `version_key` (str or `None`). |
| `DocumentPage` | The result of `list_documents`: `documents` (tuple of `DocumentSummary`) and `cursor`. |
| `DocumentSummary` | One document: `doc_id`, `title`, `source_kind`, `source_uri`, `first_seen_at`, `latest` (a `DocumentVersionSummary`), `serving`, `tags` (tuple of tag names). |
| `DocumentVersionSummary` | `version_id`, `version_no`, `status`, `ingested_at`, `error`. |
| `DocumentDeletion` | The result of `delete_document`: `doc_id`, `deleted_at`, `claims_retired`, `relations_closed`, `observations_closed`. |
| `Tag`, `TagList`, `DocumentTags` | One registered tag (`tag_id`, `name`, `description`, `created_at`, `updated_at`), the result of `list_tags` (`tags`), and the result of `update_document_tags` (`doc_id`, `tags`). |
| `ReadinessRequirements` | The capabilities a readiness check must confirm: `pipeline`, `p1`, `live_graph`, `p3`, all required booleans. |
| `PipelineReadinessReport` | `ready`, `versions` (tuple of `VersionPipelineReadiness`), `capabilities` (dict of capability name to `CapabilityReadiness`), `document_binding_generation`, `model_bindings`, `build_revision`. |
| `VersionPipelineReadiness` | `version_id`, `ready`, `stages` (tuple of `PipelineStageReadiness`). |
| `PipelineStageReadiness` | `stage`, `component_version`, `status` (`missing`, `pending`, `running`, `succeeded`, `failed`, `dead_letter`, `skipped`), `finished_at`, `defer_reason` (why waiting work waits: `no_route`, `admission`, `budget`, `scheduled`, `retry_backoff`, or `None`). |
| `ProcessingLayer` | String enum: `sources`, `claims`, `facts`. |
| `ProcessingLayerStates` | The result of `processing_layers`: `claims` and `facts`, each `enabled`, `backfilling` or `disabled`. |
| `CapabilityReadiness` | `required`, `ready`, `checked_at`, `reason`, `version`, `built_at`, `published_at`. |
| `ToolDescriptor` | One operation's descriptor: `name`, `description`, `input_schema`, `result_schema`, `result_contract`, `output_grain`, `answer_intent`, `mutates`, `version`, `implementation_plan_hash`. |
| `QueryResultDict` | A `dict` holding a `QueryResult/v1` response, with three read-only attributes: `rows` (list of rows; each row is a list of column values in column order), `columns` (list of `{"name", "type", "nullable"}` dicts) and `truncated` (bool). |
| `ClaimValidPrecision` | String enum: how narrow a stated validity window is. `unknown`, `instant`, `day`, `month`, `quarter`, `year`, `open`. |
| `TemporalMatch` | String enum: whether a fact `confirmed` or only `possible` overlapped the query window. |
| `ReadTime` | The time scope of a text read: `CurrentReadTime`, `AtReadTime`, `OverlapReadTime` or `HistoryReadTime` (in `remember.models`), chosen by `mode`. A dict such as `{"mode": "at", "at": "2026-02-01T00:00:00Z"}` is accepted wherever a `ReadTime` is. |
| `EffectivePeriodInput`, `EffectivePeriodsSet`, `DeclaredEffectivePeriod`, `EffectiveTimeCleared` | Declaring effective periods and the results of `set_effective_periods` and `clear_effective_time`. |
| `EffectiveInterval` | One in-force interval: `from_` (sent as `from`), `until`, `until_declared`. |
| `MatchingEdition`, `ScopePending`, `ClaimOccurrence` | Parts of time-scoped results: an edition that matched `search_documents`, the documents whose edition in force is still processing, and where a claim occurs in a selected version. |
| `ReferenceInput`, `ReferenceTarget`, `ReferencesSet`, `ReferenceGeneration`, `ReferenceGenerations`, `ReferenceItemError` | Supplying references and reading their generations. |
| `SectionHistoryRequest`, `SectionHistoryPage`, `SectionHistoryRow`, `SectionHistorySection`, `SectionAmendment` | `section_history`. |
| `DocumentReferencesRequest`, `DocumentReferencesPage`, `DocumentReference`, `DocumentReferenceSource`, `DocumentReferenceTarget`, `NamedReferenceTarget`, `ReferenceWindow`, `DocumentReferencesTooBroad` | `document_references`. |
| `ConnectorCreate`, `ConnectorDescriptor` | Connector configuration models. No deployment serves connectors today. `ConnectorCreate` refuses a `configuration` key that looks like a secret (`token`, `password`, `api_key` …) and asks for `credential_ref` instead. |

<Callout type="note">

`QueryResultDict.rows` is annotated as a list of dicts, but each row
arrives as a list of values. Pair it with `columns` to get names:
`[dict(zip([c["name"] for c in res.columns], row)) for row in res.rows]`.

</Callout>

### Windows credential files

Automatic credential-file reads are refused on Windows because the SDK cannot
prove owner-only access with its current file reader. Supply an explicit API key
and engine URL instead; no stored file is read when both are supplied. An argument
or environment signed key without a URL also works: it bypasses the unavailable
store and discovers its engine through its own issuer.
