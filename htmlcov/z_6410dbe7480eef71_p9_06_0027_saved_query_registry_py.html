1"""Create the saved-query registry: identities and immutable versions (§5). 

2 

3A saved query has a stable identity and an append-only history. Editing one 

4does not change what an earlier caller ran — it adds a version — because a 

5saved query is something other people's work depends on, and silently changing 

6what a name means is the failure this shape exists to prevent. 

7 

8Every version pins the `surface_manifest_hash` it was validated against. When 

9that hash changes, active versions move to `pending_revalidation` in the SAME 

10transaction that publishes the new hash, so there is no instant at which a 

11version claims validation against a surface that no longer exists. That state 

12is deliberately non-executable: a query validated against a different surface 

13is a query nobody has checked. 

14 

15Registry SQL can contain customer data — a WHERE clause naming a person is 

16customer data — so the tables carry no dependency that would prevent a hard 

17delete, and D74 purges the text while audit keeps only ids, hashes, actor, and 

18action. Version *content* is immutable in PostgreSQL; only lifecycle fields 

19may transition. 

20"""

167-- Content columns are immutable. Lifecycle fields may transition. 

168CREATE FUNCTION saved_query_versions_reject_content_mutation() 

169RETURNS trigger 

170LANGUAGE plpgsql 

171AS $$ 

172BEGIN 

173 IF NEW.sql IS DISTINCT FROM OLD.sql 

174 OR NEW.query_hash IS DISTINCT FROM OLD.query_hash 

175 OR NEW.parameter_schema IS DISTINCT FROM OLD.parameter_schema 

176 OR NEW.declared_result_schema IS DISTINCT FROM OLD.declared_result_schema 

177 OR NEW.declared_interpretation IS DISTINCT FROM OLD.declared_interpretation 

178 OR NEW.query_space_major IS DISTINCT FROM OLD.query_space_major 

179 OR NEW.default_limits IS DISTINCT FROM OLD.default_limits 

180 OR NEW.author_principal IS DISTINCT FROM OLD.author_principal 

181 OR NEW.created_at IS DISTINCT FROM OLD.created_at 

182 OR NEW.deployment_id IS DISTINCT FROM OLD.deployment_id 

183 OR NEW.query_id IS DISTINCT FROM OLD.query_id 

184 OR NEW.version IS DISTINCT FROM OLD.version 

185 THEN 

186 RAISE EXCEPTION 

187 'saved_query_versions content is immutable after insert' 

188 USING ERRCODE = 'integrity_constraint_violation'; 

189 END IF; 

190 RETURN NEW; 

191END; 

192$$; 

193 

194CREATE TRIGGER saved_query_versions_immutable_content 

195 BEFORE UPDATE ON saved_query_versions 

196 FOR EACH ROW 

197 EXECUTE FUNCTION saved_query_versions_reject_content_mutation(); 

198"""
