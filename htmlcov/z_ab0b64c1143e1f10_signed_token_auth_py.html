1"""Verify signed perimeter credentials against published public keys. 

2 

3The reference adapter for the D61 auth-perimeter port, beside the self-host 

4``HashedBearerAuth``. 

5 

6## Why a signature rather than a shared secret 

7 

8``HashedBearerAuth`` compares a presented secret against **one** digest handed 

9to the process as configuration. That is exactly right for a self-host 

10deployment and it has a hard ceiling: one credential. Reaching two means 

11pushing two digests, so every credential a customer mints becomes a deployment 

12event — configuration churn, a reload, and a window where the issuer and the 

13process disagree about what is valid. 

14 

15This adapter inverts what the process holds. It keeps **public keys** and 

16checks a signature, so the number of credentials in circulation stops being a 

17property of the deployment's configuration. One key serves one caller or ten 

18thousand, and nothing has to be pushed before a freshly issued credential 

19works. 

20 

21Public keys, not shared secrets, for a second reason: a deployment that is 

22compromised cannot mint credentials for itself. It can only verify. 

23 

24## What it deliberately does not do 

25 

26No table, no lookup, no user model, no notion of "which customer" beyond the 

27single deployment this process serves (D60/D61). Verification is arithmetic 

28over the presented bytes plus configuration held in memory. 

29 

30The cost of that is honest and bounded: **a valid signature cannot be 

31withdrawn.** A credential is good until it expires, unless its id appears in 

32the revocation set this adapter is given. Browser credentials live minutes and 

33rely on expiry alone; long-lived credentials rely on the set. 

34"""

175 def _select_key(self, *, token: str) -> PyJWK: 

176 """Resolve the verification key named by the token's ``kid``. 

177 

178 Named, never searched. Trying every key until one works would let a 

179 caller who obtained *any* accepted key sign for a deployment that key 

180 was rotated away from, and it turns key rotation into a period where 

181 old signatures silently keep working.

304def _assert_ed25519_public_key(*, raw: dict[str, Any], kid: str) -> None:

306

309 here:
