1"""The operator-only quarantine report for legacy and orphaned rows. 

2 

3The public views are fail-closed: a row whose lineage, version, reading, or 

4provenance is missing, tombstoned, or mismatched is simply absent. That is the 

5right behaviour for a caller, and the wrong behaviour for an operator, who 

6would otherwise have no way to notice that rows are quietly disappearing — 

7absence in a query surface looks exactly like absence in the corpus. 

8 

9This report closes that gap without weakening the surface. Each probe counts 

10rows that exist in the base tables but can never reach `memory_v1`, and names 

11the repair the count implies. Two of the probes exist precisely because a 

12fail-closed rule would otherwise be silent: an entity whose merge chain does 

13not terminate resolves to no survivor, and a knowledge page whose every cited 

14target has been forgotten is not published — in both cases the row is right to 

15be absent and wrong to be invisible to an operator. 

16 

17It is deliberately operator-only: it exposes counts rather than content, it is 

18not part of the query space, it is not reachable from any agent surface, and 

19nothing in it can be joined back into a public result. Orphans stay omitted 

20from every public path until they are repaired; the report only makes them 

21countable. 

22"""

302def orphan_quarantine_report( 

303 *, connection: Connection, deployment_id: str | None = None 

304) -> QuarantineReport: 

305 """Count rows that exist but can never reach the public query space. 

306 

307 Passing no deployment reports across the whole database, which is the 

308 operator view; passing one scopes every probe to that deployment. 

309 """ 

310 categories = tuple( 

311 QuarantineCategory( 

312 category=probe.category, 

313 explanation=probe.explanation, 

314 repair=probe.repair, 

315 row_count=int( 

316 connection.execute( 

317 statement=text(probe.sql), 

318 parameters={"deployment_id": deployment_id}, 

319 ).scalar_one() 

320 ), 

321 ) 

322 for probe in _PROBES 

323 ) 

324 return QuarantineReport(deployment_id=deployment_id, categories=categories)
