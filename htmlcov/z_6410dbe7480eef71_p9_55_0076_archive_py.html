1"""D159 archive: archived lineages, the renamed currency reason, the reopen outcome. 

2 

3Archive replaces D135's public delete. An archived lineage keeps every row 

4(it stays readable as history) and is recorded on ``documents.archived_at`` and 

5``archived_by`` (``caller`` or ``source``); ``deleted_at`` remains only for 

6forget's hide. The currency reason ``version_deleted`` is renamed 

7``version_archived``, and ``reopened_unarchive`` records an unarchive (or a 

8returning claim) reopening a fact an archive closed, without erasing the close. 

9 

10Upgrade of D135 data: every lineage D135 deleted (and no D74 forget owns), 

11recognised by its signature — the lineage tombstoned with no version left 

12live — becomes an archive — ``caller`` for an explicit delete, ``source`` for a 

13connector-observed deletion — with ``archived_at`` set to its deletion time. 

14The currency events and closures of that lineage's current deletion episode 

15(the delete or connector finalization, plus the late reconcile runs of the 

16episode) are re-labelled with the one archive reconciliation id unarchive looks 

17for, and only the version tombstones the lineage deletion set (same instant as 

18the lineage's) are cleared. An earlier deletion the lineage already came back 

19from is left alone, and so are internal version tombstones. 

20 

21Belief intervals: once a fact can be reopened, ``invalidated_at`` holds only 

22its current state. ``rememberstack_graph_internal.fact_believed_at`` refines 

23the single-column test from the fact's close and reopen adjudications, and 

24``memory_v1.facts_as_of``, the graph traversal helpers and the Python graph 

25reads apply it, so a read inside an archive interval still sees the fact 

26closed. 

27"""

486def _d135_run_ids(*, doc_id: UUID, at: datetime) -> tuple[UUID, ...]: 

487 """The run ids D135 derived for a lineage's deletion episode. 

488 

489 A run that closed a fact without retiring a claim (its claim was already 

490 non-current) left no currency event to find it by: the caller's delete, 

491 the connector finalization, and the operator grain. D135 rendered the 

492 instant with ``isoformat()`` in the session time zone: ``at`` as this 

493 session reads it carries that offset, and the UTC rendering covers a UTC 

494 session. 

495 """ 

496 instants = sorted({at.isoformat(), at.astimezone(UTC).isoformat()}) 

497 return tuple( 

498 uuid5(NAMESPACE_URL, f"rememberstack:{kind}:{suffix}") 

499 for kind, suffix in ( 

500 *(("delete-lineage", f"{doc_id}:{instant}") for instant in instants), 

501 *(("finalize-delete", f"{doc_id}:{instant}") for instant in instants), 

502 ("delete-lineage", f"{doc_id}"), 

503 ) 

504 )

507def upgrade() -> None: 

508 """Add the archive columns, rename the reason, convert D135 deletions.""" 

509 # The new outcome must be committed before the belief function below can 

510 # name it (PostgreSQL refuses a new enum value in its own transaction). 

511 with op.get_context().autocommit_block(): 

512 op.execute( 

513 "ALTER TYPE adjudication_outcome ADD VALUE IF NOT EXISTS 'reopened_unarchive'" 

514 ) 

515 for statement in _SCHEMA: 

516 op.execute(statement) 

517 connection = op.get_bind() 

518 # A D74 forget owns its lineage whether the forget slice has already turned 

519 # its manifests into forget records or not. 

520 forget_table = connection.execute( 

521 text( 

522 "SELECT coalesce(to_regclass('public.forgets')," 

523 " to_regclass('public.forget_manifests'))::text" 

524 ) 

525 ).scalar_one() 

526 rows = ( 

527 connection.execute( 

528 text( 

529 _DELETED_LINEAGES.text.format( 

530 forget_table=forget_table or "(SELECT NULL::uuid AS doc_id)" 

531 )
