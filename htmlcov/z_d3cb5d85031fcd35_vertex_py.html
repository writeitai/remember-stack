1"""The Vertex AI managed open-model generation adapter: keyless, priced by table. 

2 

3Google's managed open models ("Model as a Service", MaaS) on the Gemini 

4Enterprise Agent Platform (formerly Vertex AI) expose an OpenAI-compatible 

5chat-completions route. This adapter binds ``ModelProviderPort.generate`` to 

6that route for one project and location. It deliberately does not embed: 

7embeddings stay with the provider that owns the deployment's vector space, so 

8swapping the generation model never silently changes stored vectors. 

9 

10Two properties differ from the OpenRouter binding and shape this module: 

11 

12* **No Google API or service-account key.** Authentication is a short-lived 

13 OAuth access token from Google Application Default Credentials (ADC). On the 

14 benchmark hosts ADC is X.509 Workload Identity Federation: the host protects 

15 a client certificate and private key, and the provider can revoke that narrow 

16 identity independently of everything else. 

17* **No inline charge.** The response reports token counts but never a dollar 

18 amount, so ``cost_usd`` is *computed* from a pinned per-model price table. 

19 The adapter refuses to call a model whose price is not pinned, and charges 

20 every prompt token at the full input rate (cached-token discounts are 

21 ignored) so the ledger can only over-report, never under-report. 

22 

23Endpoint shape (retrieved 2026-09-04 from 

24https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/maas/call-open-model-apis): 

25``POST https://{LOCATION}-aiplatform.googleapis.com/v1/projects/{PROJECT}/locations/{LOCATION}/endpoints/openapi/chat/completions``; 

26the ``global`` location uses the bare ``aiplatform.googleapis.com`` host. 

27"""

178 """Mint bearer tokens from Google ADC, refreshing only when expired. 

179 

180 ADC resolves ``GOOGLE_APPLICATION_CREDENTIALS``; on the benchmark hosts 

181 that is an external-account file whose subject token is an X.509 client 

182 certificate exchanged over mTLS with Google STS. Nothing here ever reads a 

183 service-account key. ``google-auth`` is imported lazily so the core 

184 package keeps its small dependency set; the ``benchmark`` extra provides it. 

185 """

197 except google.auth.exceptions.DefaultCredentialsError as error: 

198 raise VertexRequestError(

207 with lock:

210 credentials.refresh(transport)
