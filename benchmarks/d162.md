Each replay matched every column of `chunks`, `chunk_search`, and
`selection_results` after aligning the creation clocks and IDs to the
checkpoint. The embedding requests matched the pinned plain `nebius`
routing, dimensions, and ordered input hashes. The checker re-ran Selection
using the persisted Selection payloads as replies, compared output, cards, and truncation,
and checked each D122 producer order and input stamp. It used empty Claimify
replies to capture the ordered request stream and exercise Claimify's
completion stamp. The pre-D162 worker and adapter code at
`167650accfc6c873644f32ce2784881b264fc7ba` and the PR implementation produced
the same digests for 272 embedding, 2,229 Selection and 1,848 Claimify requests.
The digests cover each request's stage, target, method, URL and JSON payload.
Both runs observed zero splits and zero live provider calls. SHA-256 of the
sorted `conversation request_sha256` lines, each ending in a newline, was
`a7464144a66e4c9565bc00fc5fa4fd9a3e6503ce074b1e44977a04f1df5c0152`.
The round-three implementation reproduced all ten reports against the saved
pre-D162 reports.

Run the checker on each local restore. For Full-v45, start PostgreSQL 19rc1
and SeaweedFS 4.44 from the backup, export the artifacts using their original
object keys, and migrate the local database before the replay clones it.

```bash
REMEMBERSTACK_DATABASE_URL="$LOCAL_CHECKPOINT_DB" uv run alembic upgrade head
uv run --no-sync python -m benchmarks.d162_replay \
  --database-url "$LOCAL_CHECKPOINT_DB" --artifacts "$FROZEN_ARTIFACTS" \
  --routing locomo-v45 --checkpoint-only > after.json

d162_baseline=$(mktemp -d)
git archive 167650accfc6c873644f32ce2784881b264fc7ba src/rememberstack src/remember \
  | tar -xf - -C "$d162_baseline"
PYTHONPATH="$d162_baseline/src" uv run --no-sync python -c '
from unittest.mock import patch
from benchmarks.d162_replay import main, OpenRouterModelProvider
with patch.object(OpenRouterModelProvider, "uses_hosted_embedding_ceiling",
                  create=True, return_value=False):
    main()
' --database-url "$LOCAL_CHECKPOINT_DB" --artifacts "$FROZEN_ARTIFACTS" \
  --routing locomo-v45 --checkpoint-only > before.json
cmp before.json after.json
```

Full historical parity for the 9,687 Full-v45 claims, occurrence links and
evidence spans remains open. The archive inventory lists database and object
store snapshots, run artifacts, and mounts. At the frozen source revision
`13ce4a5224709b3e3cda65c429d5915d47e95e89`, the ingestion worker constructed
its OpenRouter adapter with the default recorder value of `None`. The original
extraction wire requests and Claimify replies are still needed. Pass
`--wire-tape "$FROZEN_WIRE_TAPE"` in place of
`--checkpoint-only` to run the strict comparison. It checks the ordered
requests, reapplies the saved claim vectors through the P1 writer to reproduce
their attestations, and fails on a row difference or a split. The PostgreSQL
test exercised this path with a recorded local fixture containing an embedded
claim. It matched every claim and occurrence column, including the vector,
attestations and evidence spans.
